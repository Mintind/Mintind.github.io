Ubuntu Server 22.04-VMware

发表于 2025-12-01 分类于 SetupEnv 本文字数： 475

摘要

参考：https://blog.csdn.net/u010308917/article/details/125157774

Ubuntu Server 22.04 LTS下载

下载地址：https://cn.ubuntu.com/download/server/step1#releases

没有再老的版本了，就22.04.5吧

新建虚拟机

VMware新建虚拟机-典型。使用iso

磁盘大小，40

系统安装

开机。前面都不管，网络这里感觉用静态IP好一点。ipv4改成manual。选了vmvet8所在网段

记一下存储结构

勾选openssh

设置用户名登录密码那里，使用终端时的前缀就是username@servername，其实就是用户名和机器名。第一个your name是干嘛的还不知道

等待安装…然后重启

如果出现“[FAILED] Failed unmounting /cdrom”错误，且提示“Please remove the installation medium, then press ENTER: Unmounting /cdrom”，则按下 ENTER 回车键让它继续重启

出现了

登录

配置

网络

怎么又改了好难用。现在叫虚拟网络编辑器。这个不改，记住子网和网关

主机配置VMnet8。搜索网络连接（或者控制面板-网络-网络适配器），VMnet8编辑ipv4。这个配置ip、掩码和网关，和上面一致

VMware虚拟机设置中网络适配器选择VMnet8（NAT）

然后Ubuntu Server的配置也要配套，不过我安装的时候就配置了静态IP。

进入/etc/netplan目录，编辑目录下的那个yml文件就行

如果发现设置没变的话可以运行一下，应用配置

发现重启之后会变回去于是又找了原因，是因为在 Ubuntu Server（尤其是克隆或云镜像版）中，cloud-init 在每次引导时都会根据底层硬件或虚拟机的元数据重新生成网络配置

禁用cloud-init 的网络管理：
