配置

设置自动压缩大小

修改配置文件 ~/.codex/config.toml里的model_auto_compact_token_limit

默认的是80m

迁移默认配置路径

默认配置路径C:\Users\usr\.codex，把文件全部贴到目标位置，然后设置环境变量

sandbox模式

选项一就是elevated，选项二是unelevated

特性 elevated (首选) unelevated (备选)
权限级别 专用低权限沙箱用户 从当前用户派生的受限令牌
文件系统隔离 基于 ACL 的严格边界 基于 ACL 的边界（较弱）
网络控制 防火墙规则 + 专用离线用户规则 环境级离线控制（无专用防火墙规则）
本地策略 会应用本地策略更改 不应用
适用场景 管理员允许的环境，最强安全 企业策略阻止管理员设置时的降级方案
UI 隔离 默认使用私有桌面（Winsta0\Default） 同上

建议是优先使用 elevated，除非因企业组策略等原因无法启用管理员权限的配置。unelevated作为fallback
