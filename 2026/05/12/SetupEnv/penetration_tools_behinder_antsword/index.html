aspowershell

终端输出乱码问题

chcp查看使用的活动代码页，这里是936，需要把编码方式改为对应的GBK

chcp 是 Windows 命令提示符下用来**显示或更改“活动代码页”**的内部命令。不带参数运行时，它会在屏幕上打印当前活动代码页编号

每个代码页编号都对应一种具体的字符编码

  • 936 → GBK（简体中文字符集，也是中文版 Windows 的默认值）
  • 65001 → UTF-8（Unicode 编码，Web 和跨平台常用）

右键shell，选择编辑数据，改编码设置。记得点保存

重新连接就没有乱码了
