发表于 2026-04-14 更新于 2026-08-14 分类于 SetupEnv 本文字数： 1.2k

摘要

WSL: Linux on Windows Explained

文档：https://learn.microsoft.com/en-us/windows/wsl/

极速搭建开发环境： 直接在 Windows 上运行 Python、C++、Rust、Go、Node.js 等 Linux 版本的开发工具链，避免环境配置带来的繁琐。

使用强大的 Shell 工具： 可以在 Windows 下原生使用 grep、sed、awk 等文本处理神手，以及高效的 zsh 或 fish。

容器化开发： 与 Docker Desktop 深度集成，利用 WSL 2 的 Linux 内核运行 Docker 容器，性能远超传统的 Hyper-V 模式。

跨系统文件互操作： 你可以在 Linux 终端里编辑 Windows 磁盘上的代码文件，也可以在 Windows 资源管理器里像访问 U 盘一样访问 Linux 的文件系统。

运行 Linux 图形应用： 现在的 WSL 2 支持原生 Linux GUI 程序（如编辑器、浏览器甚至是简单的游戏）。
