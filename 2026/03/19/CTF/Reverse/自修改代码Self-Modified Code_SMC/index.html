自修改代码Self-Modified Code（SMC）

是一类特殊的代码技术，即在运行时修改自身代码，从而使得程序实际行为与反汇编结果不符，同时修改前的代码段数据也可能非合法指令，从而无法被反汇编器识

解法：

根据静态分析结果直接修改程序二进制文件

在动态调试时将解密后的程序从内存中 dump 下来。
